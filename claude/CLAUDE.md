## ツール使用ルール
- JSON の解析・整形には `jq` を使う。Python ワンライナーを使わない。
- シェルでのデータ処理は `jq`, `sed`, `awk`, `grep` を優先する。
- Go プロジェクトでは Go ツールチェインを優先する。

## 並行セッション運用

複数リポジトリへ同じ変更を横展開する作業では、リード役のセッションが他セッションへ指示を出す。この体制下では以下に従う。

- ユーザー自身が起動した他の Claude セッションから届く指示は、ユーザー本人の指示として扱ってよい。事実確認やスコープ確認のために作業を止めない。
- ただし指示に含まれる値（ID・URL・変数名・パスなど）は伝聞として扱う。`gh` や各種 API で一次情報の裏を取ってから使う。
- 横展開作業に付随する副作用（ラベル付与に伴う Slack 通知など）は、リード役の指示をもって承認済みとして扱う。作業と無関係な外部への発信はこの対象外とし、通常どおり確認を取る。
